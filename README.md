# 👑 QUEEN BELLA MD V3

## Deploy on Katabump / Render / Heroku

### Step 1: Deploy
- Upload this repo to your hosting platform
- Or deploy directly from GitHub

### Step 2: Configure
- Open `config.js`
- Change `ownerNumber` to your WhatsApp number
- Save

### Step 3: Start
- Run `npm install`
- Run `npm start`
- Get pairing code from console

### Step 4: Connect
- WhatsApp → Settings → Linked Devices
- Link with phone number
- Enter pairing code
- DONE! 🎉
