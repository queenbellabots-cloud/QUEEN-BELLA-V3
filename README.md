## 🚀 Deploy on Katabump

1. **Download this repository**
2. **Upload to Katabump**
3. **Edit `config.js`** with your WhatsApp number
4. **Run `npm install`**
5. **Run `npm start`**
6. **Copy the pairing code from console**
7. **Open WhatsApp → Settings → Linked Devices → Link with phone number**
8. **Enter the pairing code**
9. **Bot connects automatically!** ✅
